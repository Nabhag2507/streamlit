streamlit is a framework works on python code, python's declarative code.
doesn't need html/css/js only pure python.

-- run project
    streamlit run main.py

-- related to text:
    st.title("")
    st.subheader("")
    st.text("")
    st.write("")
     - this will generate green background text

-- boxes:
    st.success("")
        - light green background text
    st.info
        - light blue background text
    st.

-- markdown
        - st.markdown("---")
            - same as st.divider()
            - this will generate a horizontal thin line
        - st.markdown("#")
            - heading, can also use ##, ### for smaller headings
        - st.markdown("> blockquote")

-- drop down: 
    st.selectbox("Select options", ["first", "second", "third"])
    - can also store this into any variable

    variable = st.selectbox("Select options", ["first", "second", "third"])
    on screen it will still give same result

-- multiselect:
    st.multiselect("", [])
        - works same as select drop down but here we can select more then 1 item where as in selectbox only one is allowed

-- radio button:
    radio_button = st.radio("Choose tea base : ", ["milk", "water", "something"])
    same as drop down

-- slider:
    st.slider("Sugar level", 0, 10, 2)
    0 and 10 are range 10 included and as for 2 it is by default selected value

-- controlled input:
    st.number_input("How many cups do you want?", min_value = 1, max_value = 10)

-- text input:
    st.text_input("Enter your name")

-- date input
    st.date_input("Enter your dob")

-- sidebar:
    for sidebar above all things work same as in normal 
    just use st.sidebar.______

-- columns:
    c1, c2 = st.columns(2)

    with c1:
        pass
    with c2:
        pass
    // we can use exact same widgets as above in with c1: block it will appear in column 

-- expander:
    - this will create expandable menu with good animations
    with st.expander("Show instructions"):
        st.write("""
            1. step 1
            2. step 2
            3. step 3
        """)


-- conditions:
    if (st.button):
        do something
    - will do process if the button is clicked

    if (st.checkbox("click me")):
        do something
    - will do process if the checkbox is ticked
